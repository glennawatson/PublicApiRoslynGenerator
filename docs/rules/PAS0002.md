# PAS0002 — Public API in the baseline no longer exists

| Item | Value |
| --- | --- |
| Category | PublicApi |
| Severity | Error |
| Code fix | None |
| Default | Enabled |

The baseline records an API that the assembly does not expose. Removing it can break consumers that
call it or derive from its containing type. An explicit baseline edit makes the removal part of the
compatibility review.

## When it fires

Only projects with an available, syntactically valid baseline are checked for removals. The
diagnostic marks each baseline declaration without a matching API in the target framework being built.

- A recorded type or member has been deleted, renamed or moved to a different namespace or type.
- A recorded declaration has become inaccessible outside the assembly, such as a public property
  changed to `internal`.
- A method or constructor has changed its generic parameter count, parameter types or reference
  modifiers (`ref`, `in`, `out`), leaving the old signature absent.
- A recorded assembly attribute application is absent, including when its arguments have changed.
- A declaration retained in the baseline is excluded from the project's surface by configuration.

### Not reported

- A matching declaration with different details, such as a property's type or nullability.
  PAS0003 reports that change.
- An API absent from both the baseline and the exposed surface.
- Removals when the baseline is missing, unavailable or malformed. PAS0004 covers a missing
  configured baseline when enabled; PAS0005 covers malformed baseline text.

## Examples

The source declares `Value` but no `Gone` property:

```csharp
namespace Sample;

public class Thing
{
    public int Value { get; set; }
}
```

The baseline in `PublicAPI/net10.0/PublicAPI.txt` still records `Gone`:

```csharp
namespace Sample;

public class Thing
{
    public Thing() { }
    public int Value { get; set; }
    public int Gone { get; set; } // PAS0002
}
```

To accept the removal, keep the source and remove the stale entry from the baseline:

```csharp
namespace Sample;

public class Thing
{
    public Thing() { }
    public int Value { get; set; }
}
```

Restore the removed API in source instead if compatibility must be preserved. If a PAS0001 or
PAS0003 diagnostic is also present, its *Update the public API baseline* fix can accept removals
along with every other change in that target framework's baseline. Review the whole diff; a
removal alone has no code fix.

## Configuration

The default severity is `error`. The severity entry is:

```ini
dotnet_diagnostic.PAS0002.severity = error
```

For this baseline-file diagnostic, apply it project-wide in a `.globalconfig` with `is_global = true`,
or a project-level `.editorconfig` marked `is_global = true`, outside any file sections.

The shared `publicapisharp.include_assembly_attributes`, `publicapisharp.include_generated_code`,
`publicapisharp.excluded_attributes`, `publicapisharp.included_attributes` and
`publicapisharp.excluded_namespace_prefixes` settings control the surface checked for removals;
see [Configuration](../../README.md#configuration).
`EnablePublicApiBaseline`, `PublicApiBaselineDirectory`, `PublicApiBaselineFileName` and
`PublicApiBaselineFile` control baseline setup and placement; see
[Multi-targeting](../../README.md#multi-targeting).

The code fix updates files named `PublicAPI.txt`; edit a differently named baseline directly. For
custom surface options used with the code fix, put them in `.globalconfig` with `is_global = true`:
the fix does not apply options from `.editorconfig` sections.

Changing the surface options does not remove entries from an existing baseline. Review and update
the baseline as part of changing what the project tracks.

## When to suppress

Suppress removals temporarily in a project undergoing an intentional compatibility break while its
replacement API and baseline are being reviewed. Accepting the reviewed baseline is the permanent
resolution. To disable removal checks for that project, put this in its `.globalconfig`:

```ini
is_global = true
dotnet_diagnostic.PAS0002.severity = none
```

A pragma on a source declaration does not suppress a diagnostic located in the baseline file.
