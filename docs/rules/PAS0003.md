# PAS0003 — Public API differs from the baseline

| Item | Value |
| --- | --- |
| Category | PublicApi |
| Severity | Error |
| Code fix | Yes — *Update the public API baseline* |
| Default | Enabled |

An exposed declaration matches an API recorded in the baseline but has different declaration text.
Changes to its type, parameters or contract can break callers or derived types even when its name
is unchanged. The diagnostic marks the declaration in source and shows the baseline and current forms.

## When it fires

Only projects with an available, syntactically valid baseline are checked for changes. A declaration
matches by its qualified name and generic parameter count; ordinary methods, constructors and
indexers also need matching parameter types and reference modifiers (`ref`, `in`, `out`).

Differences in the recorded declaration include:

| Change | Effect on consumers |
| --- | --- |
| Method return type, property type or field type | Assignments and call sites can stop compiling. |
| Parameter name or default value | Named arguments can break; recompiled callers can pass a different default. |
| Return or property nullability | Callers can receive different nullable warnings. |
| Accessibility that remains externally visible; `virtual`, `abstract`, `sealed`, `static`, `required` or `readonly` | Access, construction, overrides or call patterns can change. |
| Property accessors, base types, interfaces or generic constraints | Consumers can lose supported operations or valid type arguments. |
| Constant or enum value | Code depending on the value can change behavior. |
| Attributes retained by the configured filters | Behavior depending on those attributes can change. |

Hand-edited baseline spacing within a declaration or attribute ordering can also cause a mismatch.
Keep the baseline's generated declaration form when editing it.

### Not reported

- An API missing from the baseline or missing from the exposed surface; PAS0001 and PAS0002 cover
  additions and removals.
- A method renamed, moved, or given different parameter types, reference modifiers or generic
  parameter count; its old signature and new signature are treated as a removal and an addition.
- Internal or private implementation details, including method bodies, that do not change the
  recorded surface.
- Source member reordering alone, or attributes excluded from the surface.
- Changes to declarations excluded by the generated-code or namespace settings described under Configuration.
- Changes when the baseline is missing, unavailable or malformed. PAS0004 covers a missing
  configured baseline when enabled; PAS0005 covers malformed baseline text.

## Examples

The baseline in `PublicAPI/net10.0/PublicAPI.txt` promises an `int` property:

```csharp
namespace Sample;

public class Thing
{
    public Thing() { }
    public int Value { get; set; }
}
```

Changing the property type in source reports a difference:

```csharp
namespace Sample;

public class Thing
{
    public long Value { get; set; } // PAS0003
}
```

To preserve the recorded contract, restore the source declaration:

```csharp
namespace Sample;

public class Thing
{
    public int Value { get; set; }
}
```

To accept an intentional change instead, use *Update the public API baseline*. With the default
configuration it records `public long Value { get; set; }` in the baseline. The fix rewrites the
whole baseline for the target framework being edited, accepting other additions, changes and
removals too, so review the entire diff.

## Configuration

The default severity is `error`. Set it in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.PAS0003.severity = error
```

The shared `publicapisharp.include_assembly_attributes`, `publicapisharp.include_generated_code`,
`publicapisharp.excluded_attributes`, `publicapisharp.included_attributes` and
`publicapisharp.excluded_namespace_prefixes` settings control the surface checked for changes;
see [Configuration](../../README.md#configuration).
`EnablePublicApiBaseline`, `PublicApiBaselineDirectory`, `PublicApiBaselineFileName` and
`PublicApiBaselineFile` control baseline setup and placement; see
[Multi-targeting](../../README.md#multi-targeting).

The code fix updates files named `PublicAPI.txt`; edit a differently named baseline directly. For
custom surface options used with the code fix, put them in `.globalconfig` with `is_global = true`:
the fix does not apply options from `.editorconfig` sections.

## When to suppress

Suppress changes temporarily in a project whose API contract is deliberately being redesigned and
whose compatibility review is deferred. In that project's `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.PAS0003.severity = none
```

For an accepted library API change, update the baseline so later changes remain visible. If only
an attribute outside your compatibility contract causes noise, exclude that attribute instead.
