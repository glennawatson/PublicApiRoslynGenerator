# PAS0001 — Public API is not in the baseline

| Item | Value |
| --- | --- |
| Category | PublicApi |
| Severity | Error |
| Code fix | Yes — *Update the public API baseline* |
| Default | Enabled |

## Cause

A declaration is visible outside the assembly, but the baseline for the target framework being built
does not mention it.

```csharp
// PublicAPI/net10.0/PublicAPI.txt does not list Extra
public class Thing
{
    public int Value { get; set; }
    public int Extra { get; set; } // PAS0001
}
```

## Rule description

Everything the assembly exposes is recorded in a checked-in baseline, so a change to the surface
arrives as a reviewable diff rather than as a surprise for consumers. Adding public API is a
commitment: once shipped it cannot be withdrawn without breaking somebody, and it widens what the
project has to keep working forever.

The diagnostic is reported on the declaration itself, not against the baseline file, because that is
where the decision was made and where a reviewer needs to look.

`protected` counts as public API. A consumer can derive from a public unsealed type and reach a
protected member, so changing one breaks them exactly as a public member would. `internal` does not
count, and neither does the internal half of `protected internal` — what survives outside the
assembly is its protected half, which is already covered.

## What this rule reports

Only declarations that are externally visible and absent from the baseline. These are never
reported:

| shape | why it is fine |
| --- | --- |
| an `internal` or `private` member | not visible outside the assembly |
| a member of an `internal` type | unreachable however public the member is written |
| a compiler-synthesized record member (`Equals`, `Deconstruct`, `<Clone>$`) | derivable from the record header, which is itself recorded |
| a property or event accessor | recorded as part of its property or event |
| any declaration, in a project with no baseline file | tracking is not in use; see [PAS0004](PAS0004.md) |

## How to fix violations

Accept the addition, or reduce the accessibility:

```csharp
// Accept it: apply the code fix, which rewrites the baseline for this target framework.

// Or keep it out of the surface:
internal int Extra { get; set; }
```

The code fix regenerates the whole baseline rather than inserting a line, so one invocation settles
every difference in the project at once — including [PAS0002](PAS0002.md) entries, which have no
lightbulb of their own.

## Performance

The rule runs as a symbol action, so the per-declaration cost is a dictionary lookup. The surface is
rendered and the baseline parsed once per compilation, on first use, and shared by every callback.
